### **1. 정의**

- **<!DOCTYPE html>**
  → 문서가 HTML5 표준을 따른다는 선언. 브라우저에게 “이 문서는 HTML 표준 모드로 해석하라”는 신호를 줌.

---

### **2. 중요한 이유**

- DOCTYPE 선언 여부/방식에 따라 브라우저가 **렌더링 모드**를 다르게 적용한다.
- 올바른 DOCTYPE을 쓰지 않으면 브라우저가 예전 호환 모드(Quirks mode)로 렌더링해서 레이아웃 깨짐 등 예상치 못한 문제가 생긴다.

---

### **3. 모드 종류**

1. **Standards mode (표준 모드)**
   - 최신 웹 표준(HTML, CSS)을 기준으로 렌더링.
   - <!DOCTYPE html> 선언 시 기본 적용.
2. **Quirks mode (호환 모드)**
   - 옛날 브라우저(예: IE4, Netscape 시절)의 비표준 동작을 흉내냄.
   - 박스 모델 차이 등으로 CSS 레이아웃이 의도와 다르게 보일 수 있음.
3. **Almost Standards mode**
   - 대부분 표준 모드와 같지만, 일부 오래된 이미지 관련 동작만 옛날 방식을 따름.
