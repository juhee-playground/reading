### **1. 정의**

- <meta> 태그는 HTML 문서의 **메타데이터(metadata)** 를 정의하는 태그다.
- 메타데이터란 문서 자체의 데이터(언어, 인코딩, 뷰포트 설정 등)를 의미한다.

---

### **2. 중요한 이유**

- 브라우저가 문서를 올바르게 해석하고 렌더링하기 위해 필수적이다.
- 올바른 <meta> 설정이 없으면 문자 깨짐, 반응형 레이아웃 실패 같은 문제가 발생할 수 있다.

---

### **3. 대표적인 예시**

1. **문자 인코딩**

```html
<!-- UTF-8 인코딩을 사용해 다국어(한글 포함)를 정상적으로 표시. -->
<meta charset="UTF-8" />
```

2.  **뷰포트 설정 (반응형 웹 필수)**

```html
<!-- 화면 크기에 맞게 레이아웃을 조정. 모바일 기기에서 확대/축소 없이 보이도록 설정. -->
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
```

1. **기타 활용**
   - SEO 관련 키워드
   - 소셜 미디어 공유 시 미리보기(Open Graph)
