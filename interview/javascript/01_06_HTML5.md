### **1. 정의**

HTML5는 이전 HTML4 대비 **멀티미디어 지원, 그래픽 API, 시맨틱 태그, 로컬 스토리지** 등 다양한 기능을 추가해 현대적인 웹 애플리케이션을 지원한다.

---

### **2. 중요한 이유**

- 플러그인(Flash 등) 없이도 멀티미디어/그래픽을 지원
- 웹 접근성과 구조화된 문서 표현 강화
- 클라이언트 측 데이터 저장을 통한 성능·UX 개선
- 풍부한 웹 애플리케이션 개발 가능

---

### **3. 대표적인 기능 & 예시**

1. **<video> / <audio> 태그**
   - 브라우저에서 네이티브하게 멀티미디어 재생 지원
   - Flash 같은 외부 플러그인 불필요
2. **<canvas> 태그**
   - 2D 그래픽, 드로잉 API 지원
   - 게임, 시각화, 도형/애니메이션 렌더링에 활용
     _(예: Figma 같은 도구의 기본 드로잉 영역)_
3. **시맨틱 태그 (<section>, <article>, <header>, <footer> 등)**
   - 문서 구조를 의미 단위로 구분
   - 접근성, SEO 최적화 개선
4. **Web Storage (LocalStorage, SessionStorage)**
   - 쿠키보다 간단하고 용량 큰(key-value, 약 5MB) 클라이언트 저장소
   - 서버 전송이 없으므로 성능 향상
