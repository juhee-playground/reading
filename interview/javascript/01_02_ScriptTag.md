# **📌 <script>/<script async>/<script defer>**

### **1. 정의**

- <script>: HTML 문서에 JS를 삽입하거나 불러올 때 사용. 기본적으로 **파서를 블록(block)** 해서 JS를 다운로드 → 실행 후 다시 HTML 파싱을 이어감.
- async: JS 파일을 **병렬로 다운로드**하면서, 다운로드가 끝나는 즉시 실행 → 실행 시점이 HTML 파싱과 섞일 수 있음.
- defer: JS 파일을 **병렬로 다운로드**하지만, 실행은 **HTML 파싱이 끝난 직후(DOM 생성 완료 직전)**에 일괄적으로 실행.

---

### **2. 중요한 이유**

- <script>를 기본으로 쓰면 페이지 로딩이 멈출 수 있어 성능 저하.
- async/defer를 활용하면 **렌더링 차단(blocking)** 문제를 줄이고, 페이지 속도를 개선할 수 있음.

---

### **3. 예시**

- **async**: 독립적인 스크립트 (예: 광고, 분석 툴) → 다른 코드와 의존성이 없으므로 다운로드 끝나는 즉시 실행해도 됨.
- **defer**: DOM이 준비된 후 실행해야 하는 스크립트 (예: UI 초기화, 메인 로직) → 문서 파싱이 끝난 뒤 안전하게 실행됨.
